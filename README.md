# Memory Match

A classic card-matching memory game.

## Features

- Three difficulties: 6, 8 or 12 pairs
- Flip animations and match feedback
- Move counter and timer
- Best score per difficulty
- A How to play popup explains the rules

## Running it

Open `index.html` in a browser. There is no build step and no dependencies to install.

## Files

```
index.html   markup
styles.css   styling
script.js    behaviour
```

## Tech

Plain HTML, CSS and JavaScript.
